# idealLED BLE Studio

Web Bluetooth контроллер для светодиодных лент `ISP-*` / `IDL-*` на базе протокола [8none1/idealLED](https://github.com/8none1/idealLED).

## Возможности
- Подключение с iPhone через **Bluefy** (или с ПК/Android через Chrome/Edge) + встроенный **Демо-режим**
- Автоопределение протокола (**TYPE2** `TURN/SGLS/MULT/DOOD/DOOT`, **TYPE1** `LEDON/COLO/LIGHT/EFF`, **Legacy** `fff3`)
- AES-128-ECB шифрование и дешифрование уведомлений (`9601` / `fff4`)
- 5-битная защита регулятора напряжения ленты + 2-й градиентный цвет (`SGLS`)
- Эффекты `1..10` с реверсом, скоростью и редактором 7-цветной палитры (`960a`)
- Попиксельное рисование **Граффити** (`DOOD`) и пакетная заливка **Bulk Paint** (`DOOT` + `960a` + `DOOTCP` + `DTARTCY`)
- Настройка количества диодов (`LAMPN`), запрос версии прошивки (`VE`), синхронизация времени (`TIME`), консоль пакетов

## Запуск в Docker
```bash
docker compose up -d --build
```
По умолчанию контейнер слушает `127.0.0.1:8088` -> порт `80` (Nginx).
