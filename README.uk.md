# idealLED — Web Bluetooth контролер

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![Web Bluetooth](https://img.shields.io/badge/Web_Bluetooth-BLE-0082FC?logo=bluetooth&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/API/Web_Bluetooth_API)
[![JavaScript](https://img.shields.io/badge/JavaScript-Vanilla-F7DF1E?logo=javascript&logoColor=black)](#стек-технологій)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-CDN-06B6D4?logo=tailwindcss&logoColor=white)](#стек-технологій)
[![Docker](https://img.shields.io/badge/Docker-Nginx_1.27-2496ED?logo=docker&logoColor=white)](#запуск-у-docker-та-автодеплой)

Вебзастосунок для керування адресними та RGB-світлодіодними стрічками на контролерах **idealLED (`ISP-*` / `IDL-*` / `IDEALLED`)** прямо з браузера без встановлення офіційного застосунку.

> **Чому створено цей проєкт:** офіційний застосунок з App Store / Google Play у багатьох користувачів перестав підключатися до стрічки, зависає під час пошуку або втрачає з'єднання. Цей контролер працює напряму через Bluetooth Low Energy (BLE) за відкритим реверс-протоколом [8none1/idealLED](https://github.com/8none1/idealLED).

---

## Можливості

- **Підключення з iPhone та ПК/Android** — працює на iPhone через безкоштовний браузер **Bluefy** та на ПК/Android через **Google Chrome** / **Microsoft Edge**.
- **Автовизначення протоколу** — підтримка:
  - `TYPE2` (`TURN`, `SGLS`, `MULT`, `DOOD`, `DOOT` + `DOOTCP` + `DTARTCY`, `LAMPN`, `VE`, `TIME`)
  - `TYPE1` (`LEDON`/`LEDOFF`, `COLO`, `LIGHT`, `EFF`)
  - `LEGACY` (`fff3` / `fff4`: `TURN`, `COLOR`, `MODE`, `LIGHT`, `SPEED`, `RGB`, `LEDNUM`)
  - Вбудоване шифрування/дешифрування **AES-128-ECB** на чистому JS (`js/aes.js`) із самоперевіркою та розшифруванням вхідних сповіщень (`9601` / `fff4`).
- **Палітра та захист живлення** — колірне коло HSV, RGB-повзунки та числові поля, HEX, збережені кольори в `localStorage` (до 16 кольорів), подвійний градієнт (`SGLS`) та 5-бітний захист регулятора напруги (`>> 3`).
- **Живе прев'ю стрічки (60 FPS)** — симуляція LED-стрічки на HTML5 `<canvas>`, що відображає статичний колір, градієнт, ефекти, швидкість, реверс і пікселі графіті в реальному часі.
- **Ефекти та власна палітра** — 10 вбудованих ефектів (`01–10`, із захисним обмеженням `0–11`) + Статичний (`#0`), швидкість (`1–100%`), реверс, редактор палітри до 7 кольорів і 6 готових тем (Веселка, Вогонь, Океан, Кіберпанк, Захід сонця, Свято).
- **🎲 Рандом-режим (Auto-DJ)** — автоматична зміна ефектів, палітр або статичних кольорів через заданий інтервал (пресети `10 сек`, `30 сек`, `1 хв`, `5 хв`, `15 хв` або власне значення від `3 сек`), вибір пулу ефектів (стробоскоп `#4` вимкнено за замовчуванням), випадкова швидкість/напрямок і зворотний відлік.
- **⏰ Розклад і таймер сну** — щоденне автоввімкнення (відновлення, запуск рандому, теплий білий або веселка) і автовимкнення за часом (наприклад, о `09:00` увімкнути та о `21:00` вимкнути), таймер сну (`15`/`30`/`60`/`120` хв) та режим «Не гасити екран» (Wake Lock).
- **🖌️ Графіті та Bulk-заливка** — попіксельне фарбування окремих діодів (`DOOD`: Solid / Fade / Flash, наживо або пакетом) чи надсилання малюнка на всю стрічку (`DOOT` + RLE-стиснення + чанки `960a` + `DOOTCP` + `DTARTCY`), заливка пензлем і веселка по стрічці.
- **Налаштування стрічки та діагностика BLE** — вибір кількості світлодіодів (`1–1024`), порядок каналів RGB (`RGB`, `RBG`, `GRB`, `GBR`, `BRG`, `BGR`), запит версії прошивки (`VE`), синхронізація часу (`TIME`) та журнал TX/RX-пакетів із RAW та AES-hex.

## Як користуватися

### 1. Підключення з iPhone
Apple блокує Web Bluetooth у стандартному Safari, тому на iPhone використовується спеціальний браузер **Bluefy**:
1. Завантажте безкоштовний застосунок **Bluefy** з App Store (дозвольте йому доступ до Bluetooth під час першого запуску).
2. Відкрийте в Bluefy вашу адресу (наприклад, `https://led.mriamys.site`).
3. Натисніть **«Подключить»** (якщо стрічки не видно у списку за фільтром `ISP`/`IDL`/`IDEALLED` — натисніть **«Все BLE»**) і виберіть пристрій `ISP-...` або `IDL-...`.

### 2. Підключення з ПК або Android
1. Відкрийте сайт у **Google Chrome** або **Microsoft Edge** (через HTTPS або `localhost`).
2. Увімкніть Bluetooth на пристрої та натисніть **«Подключить»**.

### 3. Про режими, Рандом і Розклад
- **Колір** — виберіть статичний відтінок, увімкніть *Подвійний градієнт* або збережіть колір у *Мої кольори*.
- **Ефекти** — виберіть ефект `01–10`, налаштуйте швидкість, напрямок і палітру.
- **🎲 Рандом і Таймер**:
  - Увімкніть **Рандом-режим**, задайте інтервал (наприклад, 30 сек або 5 хв) і виберіть, що чергувати. Можна вимкнути непотрібні ефекти (наприклад, стробоскоп) натисканням на їхні картки.
  - У розділі **Розклад** увімкніть *Автоввімкнення* (наприклад `09:00`) і *Автовимкнення* (наприклад `21:00`).
  - > **Важливо:** у самій платі стрічки немає енергонезалежного будильника, тому **рандом і розклад спрацьовують, поки сторінка відкрита та підключена до стрічки** (зручно залишити старий телефон/планшет або вкладку на ПК з увімкненим перемикачем «Не гасити екран»).

## Як додати іконку на головний екран телефону

### iPhone (iOS) — запуск в 1 дотик одразу в Bluefy
Оскільки ярлик зі звичайного Safari відкривається в Safari (де немає Bluetooth), на iPhone краще створити ярлик через вбудований застосунок **«Команди» (Shortcuts)** — він відкриватиме контролер одразу в **Bluefy**:

1. Переконайтеся, що встановлено браузер **Bluefy**.
2. Відкрийте стандартний застосунок **«Команди»** (Shortcuts) на iPhone → натисніть **`+`** у правому верхньому куті.
3. Натисніть **«Додати дію»** → знайдіть **`URL`** і вставте:
   ```text
   bluefy://open?url=https://led.mriamys.site
   ```
   *(замініть домен на власний, якщо розгортаєте на іншій адресі)*.
4. Додайте другу дію — **«Відкрити URL»** (Open URLs).
5. Натисніть на назву/стрілку вгорі → **«На екран „Додому“»**, виберіть іконку/колір, назвіть `idealLED` і натисніть **«Додати»**.

Тепер на робочому столі iPhone буде звичайна іконка застосунку, яка одразу відкриває пульт стрічки в Bluefy.

*(Підказка: цю ж інструкцію та кнопку швидкого копіювання посилання можна відкрити прямо всередині сайту за кнопкою **«📲 На экран»** у шапці).*

### Android / ПК (Chrome / Edge)
1. Відкрийте сайт у Chrome або Edge.
2. Натисніть **Меню (⋮)** → **«Додати на головний екран»** (або **«Встановити застосунок»**).

## Стек технологій

- **Фронтенд:** Vanilla JavaScript (`js/aes.js`, `js/protocol.js`, `js/app.js`), HTML5 Canvas, Tailwind CSS (CDN), власний CSS (`css/styles.css`), PWA Manifest (`manifest.webmanifest`)
- **Криптографія та BLE:** Pure JS AES-128-ECB (`FIPS-197`), Web Bluetooth API (сервіси `fff0` / `ffe0` / `ae00`, характеристики `9600` / `960a` / `9601` і `fff3` / `fff4`)
- **Вебсервер і деплой:** `nginx:1.27-alpine`, Docker Compose, GitHub Actions

---

## Запуск у Docker та автодеплой

```bash
docker compose up -d --build
```

- Контейнер підіймає `nginx:1.27-alpine` і слухає `127.0.0.1:8088:80`.
- Оскільки Web Bluetooth працює лише в безпечному контексті (**HTTPS**), проксіюйте домен системним Nginx із TLS на `http://127.0.0.1:8088`.
- У [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) налаштовано автодеплой на сервер по SSH (`SSH_HOST`, `SSH_USER`, `SSH_KEY`) під час пушу в `main`.
